# О приложении

Приложение выполняет прогноз продаж на следующие периоды на основе фактических продаж товаров. Для составления прогноза можно выбрать либо модель Prophet, либо модель AutoArima, которые используются для прогнозирования будущих значений на основе исторических временных рядов.

## Основные разделы приложения:

• справочники (товары, категории товаров, поставщики товаров)

• продажи(по товарам, по категориям, по поставщикам)

• прогноз продаж (по категориям товаров, по товарам)

Данные справочников и продаж могут дополняться через загрузку CSV файлов или через форму на странице приложения.

Для работы с приложением необходимо зарегистрироваться.

## Порядок запуска проекта

### 1: Создайте виртуальную среду:

Желательно использовать версию Python 3.10 (в оригинале используется Python 3.10.14)

Пользователи Unix / Linux / macOS выполняют следующую команду

python3 -m venv env

Пользователи Windows запускают следующую команду

py -m venv env

### 2: Активируйте виртуальную среду и проверьте ее:

Пользователи Unix / Linux / macOS выполняют следующую команду

source env/bin/activate

Пользователи Windows запускают следующую команду

.\env\Scripts\activate

### 3:Устанавливаем необходимые пакеты из requirements.txt:

pip3 install -r requirements.txt

### 4:Создание миграции для БД:

python manage.py makemigrations

### 5:Миграция данных для таблиц:

python manage.py migrate


### 6:Создать суперпользователя:

python manage.py createsuperuser

### 7:Запуск локального сервера:

python manage.py runserver

### 8: Открытие проекта в браузере:

Запуск сервера разработки по адресу http://127.0.0.1:8000/
